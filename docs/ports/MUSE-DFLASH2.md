# Muse DFlash2 CPU implementation

Status: **integrated into mlx2 on 2026-09-15; CPU tested; not GPU qualified, selected or deployed**. Implementation and independent review occurred in an isolated snapshot before the integrator merged the changes with the newer Qwen serving and memory fixes. This documentation closeout does not change runtime source or tests.

## Concrete integration

- MIT tensor closure from `agnes-vlm-support` revision `8a5e704e0fe43cd8654c144c4ecbd4c8aececeb5`; provenance and complete notice in `provenance/muse-dflash2.*`.
- Strict external artifact binder: separate target and draft fingerprints, tokenizer identity inherited from target, shared layout/revision key, target width/vocabulary/tap validation. Current local DFlash2 single-file header was inspected without loading payload: 81 entries, 5.54 GB, no embedding/head tensors. The binder now validates the exact tensor names, shapes, dtype, byte ranges and optional shard index, and incorporates the header digest into the revision identity before allocation. Target embedding and output head are bound after strict draft loading.
- Post-layer target taps and body-only prefill. Drafter context-only append avoids vocabulary projection during prefill. DFlash2 grouped dynamic convolution and bilinear candidate selector are retained.
- Draft proposals export the actual selector-conditioned distribution q. Verification uses `min(1,p[x]/q[x])`, then normalized positive `(p-q)` on rejection; full acceptance draws the target bonus. Target p includes request temperature/top-p/top-k/min-p and history processors.
- Structured-output processors transform each external draft position before sampling through an isolated probe, so provisional drafts cannot publish failure latches, grammar caches or receipt state. The probe receives the dense draft-logit row before its mask is intersected with the selector top-k. If no selector candidate is legal, that lane proposes only its legal prefix for the round; it is not permanently demoted. The transformed selector q is the q used by rejection sampling. Unconstrained lanes retain the original no-processor call path, and `external_draft_masked_positions` proves engagement.
- Target and drafter projections run batched. Target uses segmented per-lane global/sliding KV views; draft cohorts group by pending-context length. Attention currently uses per-row SDPA. Different per-lane token budgets form separate cohorts so membership does not change a lane's draw schedule.
- Rotating rollback restores a complete pre-round snapshot and replays the accepted K/V prefix. Ring tokens evicted during verification are restored exactly. Commit consumes anchor plus accepted proposals; correction/bonus stays pending. EOS/length truncation happens inside this transaction.
- External request RNG belongs to the lane. New APC requests use their new seed; explicit same-lane continuation can opt into restoring sidecar RNG. Failed rounds restore target, draft, hidden taps, RNG, tokens, pending token, generated count and queued outputs atomically.
- APCv2 pairs target state with external draft KV, pending target features, RNG bytes, covered token count and bound identity. Disk spill/restore preserves the external sidecar kind and binding. An ordinary-only prefix hit is rebuilt from transcript for external execution; missing draft state is never fabricated. Existing APCv2 COW manifests retain the historical internal draft-plane label `mtp_draft`; this is shared cache infrastructure, not self-MTP execution or a legacy APC backend.
- Shared serving selects the adapter's external batch factory through `backend=external_draft`; no model-name branch in request/scheduler logic. EXTERNAL_DRAFT is distinct from MTP. The live qualification gate requires external execution, proposal production, paired-cache resume and a committed segmented transaction; ordinary evidence cannot authorize this route. Actual partial rollback remains separately counted, while the required full CPU suite supplies deterministic forced-rejection and rollback oracles instead of making deployment depend on a chance production-model rejection.
- Route receipts retain lane-local cumulative DFlash rounds, proposals, acceptances and maximum target/draft widths. If the final one-token budget round uses the ordinary target, `current_execution` records that round while request-level `execution` still truthfully records earlier DFlash engagement.
- Bounded prefill yields to active decoding. Lane capacity and explicit memory reservation gate admission. The memory callback subtracts and clamps the server's mandatory process reserve. Partial-fit cohorts rotate fairly; pressure can reclaim allocator pages and at most two unleased APC checkpoints per poll, remeasuring after each; a configured lane cap never triggers eviction. A fitting partial cohort proceeds before reclamation; eviction is attempted only when no lane fits, trading possible width for checkpoint retention. Reservations account for global/windowed cache allocations, transaction/sidecar copies, activations and coexisting host/native vocabulary buffers. Estimates are deliberately unqualified pending measured native peaks. Recoverable drafter-only failure switches only the identified failing draft group to ordinary target decoding; state/revision errors fail closed. Because that fallback is permanent, those lanes use a target-only one-token path that skips draft-context append, target taps and speculative rollback. Their final APC publication has no external sidecar; transient final-budget depth-zero rounds still maintain and publish the paired sidecar.

## Remaining qualification and optimization gaps

1. No production artifact load, native GPU execution, throughput, memory-peak, long-context or server qualification has been performed. All external routes remain unqualified.
2. The verifier currently materializes full-vocabulary probability vectors on the host using NumPy/float64. This is a correctness reference, not an optimized native verifier. GPU synchronization, transfer cost and temporary memory must be measured; a native verifier can replace it only after agreement tests.
3. Snapshot/replay is exact but copies cache state and replays accepted K/V; GPU memory and throughput must be compared with a qualified compact rollback representation. No speedup is claimed.
4. Attention uses per-row SDPA while projections/MLPs are batched; fused ragged attention remains a potential optimization. The drafter groups equal pending-context lengths rather than padding arbitrary contexts.
5. Linear speculative blocks are implemented; tree speculation is intentionally not selected or declared. Vision, approximate KV, context compaction and unrelated Qwen QSA/PLE/GDN mechanisms are outside this route.
6. The local drafter fingerprint binds configuration, file name/size/mtime and validated safetensors header digests. Full payload checksumming and the first actual strict load remain part of artifact qualification.
7. Memory admission is an explicit estimate, not a measured bound. Prefill/verification geometry, native dequantization workspace and transient publication peaks require real-model qualification before serving is selectable.
